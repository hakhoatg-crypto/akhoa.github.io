Kỹ Năng Kỹ Thuật

Tập trung vào Thiết kế mạch, Vi điều khiển, IoT và Công nghệ phần mềm phụ trợ.

Vi Điều Khiển & Nhúng

  • ESP32 (Wi-Fi, Bluetooth, MQTT)
  • PIC16F877A (UART, Timer, Interrupt)
  • Raspberry Pi 4 (8GB - Edge Server)
  • C/C++ Embedded, Arduino IDE

Thiết Kế Mạch PCB

  • Altium Designer (Vẽ mạch PCB)
  • Proteus (Mô phỏng nguyên lý)

  • Thi công & Hàn mạch điện thực tế

Giao Thức Truyền Thông

  • UART / Serial Communication
  • SPI (RFID RC522) & I2C (LCD1602)
  • Wi-Fi / MQTT Protocol
  • Bluetooth BLE (HM-10)

AI & Mobile App Phụ Trợ

  • Nhận diện khuôn mặt DeepFace (FaceNet)
  • Python Flask API Server
  • Dart / Flutter App Development
  • Firebase Realtime Database

Khóa Số Điện Tử Keypad & Bluetooth

ĐỒ ÁN HỆ THỐNG NHÚNG - ĐH TÔN ĐỨC THẮNG

Mô tả chi tiết: Thiết kế và thi công hệ thống khóa điện tử xác thực kép tại chỗ. Cho phép người dùng mở khóa trực tiếp bằng bàn phím ma trận Keypad 4x4 hoặc qua ứng dụng trên điện thoại kết nối không dây qua Bluetooth HM-10 (giao thức BLE/UART).

Tính năng nổi bật:

  • Xác thực mật mã 4 chữ số bảo mật.
  • Lập trình truyền nhận nối tiếp UART giữa PIC16F877A & HM-10.
  • Thi công mạch in PCB hoàn chỉnh trên phần mềm Altium Designer.

Khóa Cửa Thông Minh Wi-Fi & Nhận Dạng Âm Thanh

ĐỒ ÁN CHUYÊN NGÀNH - ĐH TÔN ĐỨC THẮNG

Mô tả chi tiết: Hệ thống khóa cửa đa phương thức: mở cửa từ xa qua sóng Wi-Fi bằng ứng dụng Blynk hoặc mở bằng mật mã chuỗi nhịp gõ âm thanh nhận diện qua cảm biến KY-037.

Tính năng nổi bật:

  • Kết nối IoT qua Wi-Fi điều khiển mở khóa từ xa.
  • Xử lý tín hiệu âm thanh thu nhận từ micro cảm biến KY-037.
  • Tích hợp còi hú và báo động khi gõ sai mật khẩu quá 3 lần.

Nhà Thông Minh AI Face ID & RFID

ĐỒ ÁN CHUYÊN NGÀNH NÂNG CAO - ĐH TÔN ĐỨC THẮNG

Mô tả chi tiết: Hệ thống kiểm soát ra vào cao cấp kết hợp Trí tuệ nhân tạo (AI) nhận diện khuôn mặt (DeepFace / FaceNet) từ Camera Module V2 và đọc thẻ từ RFID RC522.

Tính năng nổi bật:

  • Edge Server Python Flask chạy trên Raspberry Pi 4 (8GB RAM).
  • Giao tiếp node vi điều khiển ESP32 qua giao thức MQTT.
  • Ứng dụng di động Flutter kết nối đồng bộ Firebase Realtime Database.
